# University of Nottingham website

Static HTML, CSS, and JavaScript website prepared for GitHub.

`index.html` is the home page and is located at the repository root. The other pages are alongside it. Keep the `assets` folder in place so images and local fonts continue to load.

Copy the contents of this folder into the root of your GitHub repository.

Ghayah International Academy is presented as an independent external learning resource across the pages. The placement does not indicate University of Nottingham endorsement or accreditation.
